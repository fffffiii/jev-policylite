# 离散 DPO 冒烟实验 V1

## 目的

验证从多模态偏好数据、冻结特征抽取、离散 DPO 更新到完整检查点保存的链路。该实验使用已有二元标签自动生成 Block/Allow 偏好，不代表人工反馈带来的真实提升，也不评估 Review 动作。

## 设置

- 起始检查点：`outputs/public-pilot-multihead`
- 基座：Qwen3.5-0.8B
- 硬件：NVIDIA RTX 3090，GPU 1
- 偏好样本：128 条，其中 chosen Block 78 条、Allow 50 条
- 按 `group_id` 拆分：训练 103 条、验证 25 条
- 训练：2 epochs，`beta=0.5`，学习率 `5e-4`
- 更新范围：只训练 `policy_head`；视觉骨干、LoRA、二元违规头、属性头全部冻结

## 结果

| 指标 | 训练前验证集 | 训练后验证集 |
|---|---:|---:|
| DPO loss | 0.6931 | 0.4371 |
| 偏好准确率 | 100.0% | 100.0% |
| chosen/rejected 平均对数概率边际 | 6.7104 | 7.9800 |
| 相对参考策略的平均优势 | 0.0000 | 1.2696 |
| 当前策略到参考策略 KL | 0.0000 | 0.00119 |

训练集偏好准确率从 96.12% 增至 97.09%，平均边际从 5.7241 增至 6.7855。验证集在训练前已全部排序正确，所以本轮改善体现在置信边际增加，而不是准确率变化。

## 性能与完整性

- 128 条图文特征抽取：46.23 秒
- 两轮策略头训练（含每轮验证）：0.19 秒
- CUDA 峰值显存：2.00 GiB
- 输出检查点：`outputs/policy-dpo-smoke-v1`
- 输出检查点已由现有 `load_checkpoint` / `predict.py` 成功加载并完成一次图片推理
- 新旧 `decision_head.pt` SHA-256 相同
- 新旧 `attribute_head.pt` SHA-256 相同

性能数据说明了缓存冻结特征的价值：耗时集中在一次视觉编码，增加策略头训练轮数几乎不再增加模型前向成本。正式训练应换成人工复核偏好，特别补充 Review 与 Block、Allow 的边界对比，并在固定测试集上检查误阻断率与人工复审率。
